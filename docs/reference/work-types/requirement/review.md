# Work type: `requirement` — the review checklist

The review checklist for a requirement, constraint or glossary term is the same file as the
one for a use-case: [`../uc/review.md`](../uc/review.md). Read it there.

It is one file rather than two for the same reason [`done.md`](done.md) is: the `uc` and
`requirement` rows share one reviewer over one tree, and that tree also holds documents
belonging to neither label. The checklist is selected by the tree under review, not by the row
that dispatched it. The reasoning is stated at the top of that file; nothing about the
checklist is restated here.
